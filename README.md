# RoFLy 3.1

  <img src="Rofly.png" alt="RoFLy 3.1 Banner" width="750">
</p>

**RoFLy 3.1** — это экспериментальный автономный ИИ-агент для экосистемы Roblox. Проект использует симуляцию коннектома (карты связей головного мозга) мухи **MaleCNS v1.0** в качестве базового контроллера, связывая виртуальные нейродинамические цепочки с реальным игровым процессом через захват экрана, оптическое распознавание текста (OCR) и симуляцию ввода с клавиатуры.

В отличие от классических игровых макросов или ботов на основе жестких правил, RoFLy считывает мультимодальные данные из окна Roblox, пропускает эти стимулы через масштабную нейросетевую граф-модель и генерирует комплексное социальное и двигательное поведение.

---

## Как это устроено: Инженерная петля (The Loop)

Агент работает в непрерывном цикле, обрабатывая внешнюю среду и генерируя действия через четыре ключевых узла:

*   **Слой восприятия (Perception):** Скрипт захватывает буфер экрана активного клиента Roblox. Модуль семантического зрения формирует матрицы пространственной ориентации объектов, а параллельный слой OCR непрерывно парсит внутриигровой чат, системные уведомления и элементы UI, превращая текстовые сообщения в виртуальные нейронные раздражители.
*   **Коннектомный контроллер:** Проект симулирует оригинальную структуру графа MaleCNS v1.0 без грубого обрезки цепей. Текстовые токены и зрительные маркеры симулируют сигналы в высших сенсорных центрах виртуального мозга, запуская каскадную активность по миллионам синаптических связей.
*   **Декодер движений (`roblox_decoder.npz`):** На выходе из симуляции мозга нисходящие нейронные импульсы (аналоги двигательных команд живого организма) передаются в предобученный латентный декодер. Он преобразует абстрактную биологическую активность в физические тайминги нажатия клавиш и векторы перемещения.
*   **Социальное поведение и память:** Нейродинамический баланс и внутренние базовые уровни активности сохраняются между игровыми раундами и ресетами персонажа. Это обеспечивает контекстную память, позволяя агенту стабильно реагировать на социальные триггеры и сообщения других игроков в чате.

## Системные требования и зависимости

Полнографовая симуляция биологической сети требует значительных ресурсов CPU/RAM и не может быть запущена внутри браузера или легковесных облачных функций (Edge functions).

1. **Окружение:** Требуется **Python 3.11** и установленный компилятор C++ для сборки нативного ядра симулятора.
2. **Внешнее приложение (Roblox):** Агент взаимодействует с игрой исключительно извне. Программа не содержит игровых ассетов, не модифицирует файлы Roblox и не внедряется в память процесса (без инжектов и читов).

## Быстрый запуск

### 1. Подготовка данных и окружения
Установите зависимости и разверните виртуальное окружение в папке проекта:
```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Поскольку файлы графа коннектома (`edges.feather` и `edges.arrow`) весят больше 1.3 ГБ, убедитесь, что они полностью выкачаны из Git LFS, и проверьте их целостность:
```bash
git lfs pull
python -m doom.audit_data
```

### 2. Запуск симуляции
1. Скачайте и установите официальный клиент [Roblox](https://roblox.com) (если он еще не установлен).
2. Запустите Roblox, войдите в нужный плей (игру) и оставьте окно открытым на экране.
3. В первом терминале запустите бэкенд-сервер нейросети, который будет просчитывать динамику синапсов:
   ```bash
   python -u -m doom.server --model experimental-v6 --port 8766
   ```
4. Во втором терминале запустите основного социального агента:
   ```bash
   python run_roblox_social.py
   ```
5. Как только в консоли появится запрос, немедленно кликните мышкой по окну Roblox, чтобы перевести на него фокус ввода.

*Примечание: Предобученный декодер `roblox_decoder.npz` включен в репозиторий. Вам не нужно заново собирать демонстрации движений для базовой работы бота.*
